# Actifuzz — One Dashboard
A simple productivity dashboard that replaces your browser's Home Page/New Tab page.
> Track activity, manage tasks, and monitor attendance—all in one place.

### More than 32 Features

* 👋 Greeting
* 🕒 Live IST clock (Digital & Analog)
* ⏱️ Daily work timer
* 📅 Attendance tracker
* ✅ To-do sidebar
* 🚀 Quick launch shortcuts
...

> All data is stored locally in your browser. No account, backend, or cloud storage.
> Sign-in in order to sync your data on cloud, data will remain consistent on all other devices.

## Tech Stack

* React + Vite + TypeScript
* Tailwind CSS v4
* Framer Motion
* Manifest V3


## Install (Microsoft Edge)

1. Open `edge://extensions`
2. Enable **Developer mode**
3. Click **Load unpacked**
4. Select the `dist` folder

Actifuzz will automatically replace your Home Page/New Tab page.

## Notes

* Work timer resets every day (IST).
* Attendance is tracked with a simple calendar.
* Quick Launch supports websites and app protocol links (`vscode://`, `spotify://`, etc.).
* All preferences and data are saved locally.
